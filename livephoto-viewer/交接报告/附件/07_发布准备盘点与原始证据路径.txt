二、产品定位与目标用户（只列证据与合理假设，不编造市场数据）
【事实】README.md:16「自用的 iPhone 实况照片备份与查看小工具」；:21「面向用户：彦祖本人（自用，无对外分发）」
【事实】README.md:25-28 项目目标：原样备份 .heic + .mov 双件套永不丢动态 / 自动生成 GIF 与网页查看器 / 增量备份 / 绿色单文件分发
【事实】使用说明.txt:5-8 描述的痛点：上传到云盘/移动硬盘后两个文件易被拆散或丢视频，照片变「不会动」的静态图
【事实冲突】任务书「一款面向 Windows 用户的 iPhone 实况照片备份浏览工具」属产品目标扩展假设，与「自用、无对外分发」冲突；本轮不裁定，列入主报告 D5
核心解决的问题（有证据）：备份保真 + 让静态化的照片重新可动
用户在什么情况下需要（有证据）：每年把 iPhone 照片备份到 Windows 电脑/移动硬盘之后
与 Windows 默认照片查看器的差异（不识别「图+视频」配对、不生成可动产物）属【推断】，未做竞品实测
与手机相册相比的定位（本地离线、无云服务、以文件目录为单位）属【推断】
核心需求（有证据）：配对识别 · 原样备份 · 不破坏源文件 · 生成可动产物 · 增量跳过
锦上添花（登记于 README T5 / 项目实时进度.md §5）：手动相册、导出 MP4、HEIC→JPG 独立导出、局域网分享（D7 否决项）、预览页视觉同步
用户最关心浏览/播放/整理/管理/备份哪一项：【无调研数据，不知道】；现有交付物重心在「备份」，V1.3 才转向「浏览」，属方向变化而非既证需求
