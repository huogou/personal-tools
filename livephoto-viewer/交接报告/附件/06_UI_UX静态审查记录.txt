二、V1.2 主窗口「已扫描」态（main_S4_已扫描.png）可见事实
· 标题「实况照片备份查看器」+ 徽章「V1.2」；副标题「备份 iPhone 实况照片，让动态永远不丢」；右上角「? 使用帮助」
· 两行路径输入：照片文件夹（带「浏览」+ 绿色「已扫描」标记）、备份输出到（带「浏览」）；下方提示「重复备份会自动跳过已处理的照片 · 建议备份完成并抽查后，再删除电脑或手机上的原文件」及「预计需要 18.1 MB · 目标盘可用 772.2 GB」
· 六张统计卡：发现照片 7 / 完整配对 3 / 可预览 6 / 待确认 2 / 不完整 2 / 失败 1，每张带一句解释（如「图和视频都在，可以直接备份」「同名文件多于一组，需要你人工看一眼」「个别文件读不出来，详情看日志」）
· 卡片下方橙色提示条被下方「操作日志」区遮挡、文字被截断，窗口右侧出现滚动条 → 当前窗口高度下需滚动才能看全
· 操作日志区红字可见 ffmpeg 报错：`Error opening input: Invalid data found when processing input`、`Error opening input file ...\BROKEN_01\BROKEN_01.mp4`，以及中文路径乱码片段与 8.3 短名 `C:\Users\ADMINI~1\AppData\...`
· 结论【事实】：分类与统计信息密度高、异常有明确反馈；但异常提示与日志混在同一区域，普通用户需要读英文报错才能理解失败原因
