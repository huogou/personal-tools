### §四.1 深色侧状态色映射表（V1.1 修订新增，落实评审 R-2 与复核裁定 P-3）

> **背景**：V1.2 02 号状态色（如 `#9A6700`/`#CF222E`/`#0969DA`）为浅色底设计，直接搬到深色底（`#101418`/`#1A2027`/`#222`）对比度不达标（核算见下表），故深色侧状态色采用**亮色变体**。下表全部色对经 **WCAG 相对亮度公式脚本核算**（非目测，裁定 P-3），核算工具与脚本随 12 号交付报告归档。

|---|---|---|---|---|---|
| 进行中/转码中 | `#58A6FF` | `#2F6FED`（图形 ≥3:1 达标，仅用于边框/指示条） | ● / ◐ | 7.32 / 6.50 / — | **AA ✓** |
| 成功 | `#1F9D55`（沿用网页查看器绿） | 同文字色 | ✓ | 5.30 / — / 4.55 | **AA ✓** |
| 警告 | `#E0A800` | 同文字色 | ⚠ | 8.61 / 7.63 / 7.40 | **AA ✓** |
| 待确认 | `#E8A87C` | 同文字色 | ？ | 9.09 / — / 7.82 | **AA ✓** |
| 错误/失败 | `#F85149` | `#CF222E`（图形） | ✕ | 5.52 / — / —（`#CF222E` on 深底仅 3.45，**只作图形**） | **AA ✓** |

## 五、触屏与可访问性增补

| 项 | 值 |
|---|---|
| 触屏最小点击区 | **44×44 px**（分类项、工具条按钮、卡片菜单项） |
| 触屏网格列数 | 按屏幕宽度自适应，最小列宽 150px（触屏单列过宽，显小） |
| 长按阈值 | **500ms** 唤出卡片菜单 |
| 对比度 | 正文与底色对比度 ≥ 4.5:1；徽标/计数等辅助文字 ≥ 3:1 |
| 深色网格与浅色 tkinter 并存 | 允许（照片浏览天然适合深色底），但**顶部页签条保持浅色**，与主窗口统一 |
| 动画 | 缩放/淡入 ≤ 200ms；**播放指示的出现 ≤ 120ms** |

## 六、新增状态色映射（沿用 02 号 §6 三重编码；深色侧文字色按 §四.1 映射表）

| 新增状态 | 颜色 Token（tkinter 侧） | 深色侧文字色（§四.1） | 符号 | 文字 |
|---|---|---|---|---|
| 目录相册 | `C["primary"]` | `#9FC0FF` | ▸ | 目录 |
| 手动相册 | `C["preview_green"]`（V1.1 修订：原误标 `C["success"]`） | `#7EE2A8` | ● | 手动 |
| 转码中 | `C["primary"]`（V1.2 未定义 `info`，正式定为 primary） | `#58A6FF` | ◐ | 准备中 |
| 播放失败 | `C["warning"]` | `#F85149`（错误语义升级，见注） | ⚠ | 暂时播不出来 |
| 索引异常 | `C["warning"]` | `#E0A800` | ⚠ | 索引异常 |

> 注：播放失败在 V1.2 Token 体系中最接近的是 warning；深色侧按"错误"级处理（`#F85149`），因其需要与"转码中（进行中）"明确区分——若同用黄色系会让"正在努力转"和"播不出来"混为一谈。tkinter 侧如出现该状态（备份页不出现，仅相册页）沿用 `C["warning"]`。
>
> 三重编码要求：**颜色 + 符号 + 文字**三者同时出现，不得只用颜色区分（无障碍要求，02 号 §9）。
>
> **符号清单增补**（V1.1 修订，R-4）：本页在 02 号 §7.2 基础上新增收录 **▶（U+25B6，播放指示）、◐（U+25D0，转码中）、⏸（U+23F8，暂停）**；网页查看器播放指示一律用 ▶，不得使用 ❚❚（U+275A）等其他字符。
