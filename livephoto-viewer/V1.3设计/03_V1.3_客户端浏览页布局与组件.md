# 03 · V1.3 客户端浏览页布局与组件

> 起草：CodeBuddy（开发 AI）｜日期：2026-11-02｜状态：**V1.1 修订版**（落实评审 R-7/R-8 与复核裁定 P-1：源目录双向同步、不自动触发扫描/备份）
> 视觉 Token 一律沿用 `V1.2设计\02_V1.2_桌面UI视觉设计规范.md`，本份只定义**结构与行为**，色彩/字号增量见 06 号。

## 一、骨架变更：单页 → 双页签

**现状**：主窗口单页，六区自上而下（S1 标题 → S2 路径 → S3 选项 → S4 建议 → S5 任务 → S6 日志），`root.geometry("860x680")`。

**变更**：引入页签容器，「备份」页**内部逻辑与布局逐像素保持 V1.2 原样**，「相册」页为本轮新增。

| 项 | 值 |
|---|---|
| 页签容器 | `ttk.Notebook`（Windows 主题下需自定义样式以贴合 06 号 Token），或等效自绘页签条 + `place`/`grid` 切换容器 |
| 页签 1 | **备份**（V1.2 原样，默认选中） |
| 页签 2 | **相册**（本轮新增） |
| 页签条位置 | 窗口标题栏下方第一行，高 **32px**，占满宽度 |
| 页签条背景 | `C["window"]`；选中页签底色 `C["surface"]`、顶部 2px 主色指示条 |
| 内容区 | 扣除页签条 32px 后，其余高度全部给页面内容（保持 860×680 / 最小 760×600 不变） |
| 日志区 | **仅「备份」页拥有**；「相册」页不显示日志区（浏览态无需日志），页面内容占满 |
| 风险控制 | 「备份」页所有控件**不重排、不重命名**；页签切换仅做容器显隐 → 保证 V1.2 A 组红线不受影响（RK-8） |

> **硬约束**：页签改造**不得**触碰 `process_directory` / `scan_groups` / `build_html` 等受保护函数，仅新增容器层。

## 二、「相册」页三区布局

```
┌──────────────────────────────────────────────────────────────┐
│  备份        │  相册                                          │ ← 页签条 32px
├───────────────┬──────────────────────────────────────────────┤
│               │  工具条：源目录 · 排序 · 新建相册 · 导出MP4   │ ← 工具条 44px
│  分类栏        ├──────────────────────────────────────────────┤
│  (200px)      │                                              │
│               │   网格（滚动区）                              │
│  ▸ 全部   128 │   ┌────┐ ┌────┐ ┌────┐ ┌────┐                │
│  ▸ 未分类  6  │   │卡片│ │卡片│ │卡片│ │卡片│                │
│  ▾ 目录相册    │   └────┘ └────┘ └────┘ └────┘                │
│    旅行  32   │   ┌────┐ ┌────┐ ┌────┐ ┌────┐                │
│    美食  18   │   │卡片│ │卡片│ │卡片│ │卡片│                │
│  ▾ 手动相册    │   └────┘ └────┘ └────┘ └────┘                │
│    家人  12   │                                              │
├───────────────┴──────────────────────────────────────────────┤
│  状态条：共 128 张 · 当前：旅行 · 索引已保存                  │ ← 状态条 26px
└──────────────────────────────────────────────────────────────┘
```

| 区 | 宽/高 | 内容 | 滚动 |
|---|---|---|---|
| 分类栏 | 固定 **200px** | 视图入口 + 相册树 | 独立垂直滚动 |
| 工具条 | 高 **44px** | 源目录路径、排序、新建相册、导出 MP4、刷新 | 不滚动 |
| 网格 | 弹性 | 照片卡片 | 垂直滚动（主滚动区） |
| 状态条 | 高 **26px** | 总数 / 当前相册 / 索引状态 | 不滚动 |

> **渲染边界（重要）**：「相册」页的**全部内容（分类栏 / 工具条 / 网格 / 状态条）均在 WebView2 内渲染**，tkinter 侧只承载**页签条**（32px）。因此本页所有颜色/字号一律取 **06 号 §三、§四（WebView 侧，等值十六进制）**，**不直接使用 tkinter `C[]` Token**（06 号 §三的 Token 名仅作为与 V1.2 视觉体系对齐的对照表）。

**分类栏宽度**：200px 固定，不随窗口拉伸；窗口最小宽度 760px 时，网格区仍保留 ≥ 540px（= 3 列 180px + 间距）。

## 三、分类栏规格

### 3.1 层级结构

```
▸ 全部            128     ← 视图
▸ 未分类            6     ← 视图
▸ 目录相册               ← 分组标题（可折叠）
    旅行            32
    美食            18
▸ 手动相册               ← 分组标题（可折叠）
    家人            12
    2026 春         26
```

| 元素 | 规格 |
|---|---|
| 视图项（全部/未分类） | 高 28px，缩进 0 |
| 分组标题（目录相册/手动相册） | 高 28px，缩进 0，前置 ▸/▾ 折叠箭头，**不可选中**，点击仅折叠/展开 |
| 相册项 | 高 28px，缩进 16px，选中态 = 主色左边条 2px + 浅主色底 |
| 计数 | 右对齐，caption 字号，`C["text_tertiary"]`；0 项显示 `0`（不隐藏，让用户知道相册存在但为空） |
| 「新建相册」 | 固定在分类栏底部，高 32px，虚线边框按钮 |
| 相册右键菜单 | 重命名 / 删除 / 在资源管理器中打开 |

> 色彩与字号：见 06 号 §三（分类栏）与 §四（WebView 网格区）；Token 名沿用 V1.2 `C[]` 仅作对照，渲染值为等值十六进制。

### 3.2 命名与标识

| 规则 | 说明 |
|---|---|
| 目录相册名 | 源根第一层子目录名；嵌套路径在**悬停提示**中显示完整路径（标题 `旅行/云南`） |
| 手动相册名 | 用户自定义；**允许与目录相册同名**，此时显示为「旅行（手动）」/「旅行（目录）」，**不自动合并**（Q-2） |
| 重名检测 | 手动相册之间重名 → 阻止并提示「已有同名相册」 |
| 长度 | ≤ 30 字符，超出截断并加省略号，悬停显示全名 |
| 禁用字符 | `\ / : * ? " < > |` → 阻止并提示 |
| 删除相册 | **仅删相册，不删照片**；若相册内有照片，删除后这些照片回落为「未分类」（若它们也没有目录相册） |

## 四、网格与卡片规格

### 4.1 网格

| 项 | 值 |
|---|---|
| 列 | `grid-template-columns: repeat(auto-fill, minmax(180px, 1fr))` |
| 间距 | 12px |
| 容器内边距 | 16px |
| 卡片宽高比 | **3 : 4**（实况照片原生竖版比例） |
| 加载 | 懒加载：`IntersectionObserver` 进入视口 ±200px 才加载缩略图（R-15） |

### 4.2 卡片

```
┌──────────────┐
│              │  ← 静止封面（object-fit: cover）
│              │
│  ▶           │  ← 播放指示（仅播放中显示，居中半透明圆底 ▶）
│              │
├──────────────┤
│ IMG_0346     │  ← 文件名（caption，右下渐变遮罩）
│ ▸ 旅行       │  ← 所属相册徽标（最多 2 个 + "+N"）
└──────────────┘
```

| 元素 | 规格 | 状态 |
|---|---|---|
| 封面图 | `object-fit: cover`，懒加载 | 静止时唯一可见内容 |
| 播放指示 | 居中 36px 半透明黑底圆 + 白色 ▶ | **仅播放中显示** |
| 文件名 | caption 字号，底部渐变遮罩 | 常驻 |
| 相册徽标 | 6px 高小圆点 + 名称，最多 2 个 + `+N` | 常驻 |
| 悬停 | 缩放 `scale(1.04)`，200ms（**不播放**，D5/Q-6） | — |
| 选中态 | 2px 主色边框 | 多选模式下显示 |
| 右键菜单 | 归入相册 / 新建相册并归入 / 移出相册 / 导出 MP4 / 在资源管理器中显示 / 复制文件路径 | — |

### 4.3 卡片播放状态机（单卡片）

| 状态 | 显示 | 触发 |
|---|---|---|
| `idle` | 静止封面 | 初始 / 播放结束 400ms 后 |
| `loading` | 封面 + 居中加载指示 | 点击后、媒体就绪前 |
| `playing` | 视频帧 + ▶ 指示 | 媒体就绪且 `play()` 成功 |
| `paused` | 视频当前帧 + ⏸ 指示 | 用户中途点击暂停 |
| `failed` | 封面 + ⚠ 角标 + 提示条 | 三轨全部失败 |

**关键**：**不存在"自动播放"状态**。任何进入 `playing` 的路径都必须经过一次用户点击事件（R-03/R-04）。

## 五、「相册」页状态机（8 态，V1.1 修订：A2 补取消去向）

| 态 | 触发 | 界面 | 可用操作 |
|---|---|---|---|
| **A1 未设置源目录** | 首次进入相册页（且当前无有效源目录） | 空态插画 + 说明 + 「选择照片文件夹」按钮 | 选目录（选定即扫描，属显式用户动作） |
| **A2 扫描中** | 选目录后 / 点「刷新」后 | 进度 + 已扫描计数 | 取消扫描 |
| **A3 建索引中** | 扫描完成后 | 「正在建立相册索引」+ 计数 | — |
| **A4 就绪** | 索引就绪 | 分类栏 + 网格 | 全部浏览/分类操作 |
| **A5 索引为空** | 源目录无可识别实况 | 明确说明「未找到成对的实况照片（需要 主图+同名视频）」 | 换目录 / 走导入向导 |
| **A6 索引异常** | JSON 损坏且无备份 | 明确说明「索引不可用，照片本身未受影响」+ 「从目录结构重建」/「继续浏览（无分类）」 | 重建 / 忽略 |
| **A7 转码中** | 某卡片需兜底转码 | 该卡片显示 loading + 全局状态条「正在准备可播放版本…」 | 可继续浏览其他卡片 |
| **A8 WebView2 不可用** | 运行时探测失败 | 整页降级说明 + 「用系统浏览器打开」按钮 | 降级浏览 |

> **A2 取消后的去向（V1.1 修订，R-7 / 复核补充）**：
> - 若此前**已有有效索引**（A4 曾就绪）→ 回 **A4**，沿用旧索引数据渲染，状态条明确提示「**已取消，显示上次结果**」（文案见 07 号 §二短文案表）——**不得用未完成的新扫描结果冒充旧结果**；
> - 若此前**无有效索引**（首次进入即取消）→ 回 **A1** 空态；
> - 取消 = 当前遍历安全点停止（与备份安全取消同模式），已扫描部分**不落盘**（不写半个索引）。

> A5/A6 文案口径继承 V1.2 红线 L7 与「不完整 ≠ 损坏」原则：**不得暗示照片损坏**。

## 六、前端 ↔ Python 桥接 API

WebView2 内运行的相册前端通过 `window.pywebview.api` 调用 Python（pywebview 的 JS 互操作通道）。**所有写操作经 Python 侧校验后落盘**，前端不得直接操作文件系统。

**源目录同步规则（V1.1 修订，复核裁定 P-1）**：相册页与备份页**共用同一个源目录（单一事实源）**，路径**双向同步**；**同步本身不自动触发扫描或备份**——相册页路径变更后仅更新两侧显示并提示「路径已变更，点『刷新』重新扫描」；备份页路径变更同步到相册页时同样不自动扫描。仅两种显式动作会触发扫描：① A1 空态点「选择照片文件夹」选定后；② 用户点「刷新」按钮。

| 方法 | 入参 | 返回 | 说明 |
|---|---|---|---|
| `get_state()` | — | `{state, source_root, total, album_count, index_ok}` | 供前端渲染骨架 |
| `sync_source_path(path)` | 源目录 | `{ok, synced}` | **仅双向同步路径显示**（相册页 ↔ 备份页），**不触发扫描**；路径无效/无权限/不可访问 → `{ok:false, error:"not_found"\|"no_access"}` 并携带明确状态，**不得沿用旧结果冒充新结果**（V1.1 修订 R-8） |
| `set_source(path)` | 源目录 | `{ok, total, state}` | **显式扫描动作**（仅 A1 空态按钮与「刷新」调用）：校验目录存在且可访问（不存在/无权限 → `{ok:false, error:...}` + V-21 文案，不进入 A2），通过后触发扫描 + 建索引 |
| `list_albums()` | — | `[{id, name, kind, count, path?}]` | 分类栏数据 |
| `list_photos(album_id, offset, limit, sort)` | 分页参数 | `{total, items:[{key, name, thumb, media}]}` | 网格数据（懒加载分页） |
| `create_album(name)` | 名称 | `{ok, album}` | 手动相册 |
| `rename_album(album_id, name)` | — | `{ok, album}` | — |
| `delete_album(album_id)` | — | `{ok}` | 仅删相册不删照片 |
| `assign(photo_keys, album_ids)` | — | `{ok, changed}` | 归入（多相册） |
| `unassign(photo_keys, album_ids)` | — | `{ok, changed}` | 移出 |
| `get_photo_detail(key)` | — | `{key, tracks:{video, transcode, gif}, can_play}` | 播放轨判定 |
| `export_mp4(photo_keys)` | — | `{ok, files:[], dir}` | 导出安卓友好 MP4（批量前执行空间预检，见 05 号 §四） |
| `open_in_explorer(key)` | — | `{ok}` | 在资源管理器中显示 |
| `refresh()` | — | `{ok}` | 以当前路径重新扫描（显式动作） |

**调用约定**：
1. 所有方法返回 **JSON 可序列化对象**，异常以 `{ok:false, error:"..."}` 返回，前端不得因异常崩溃；
2. 耗时操作（扫描/建索引/转码/导出）**必须异步**，Python 侧起线程 + 前端轮询或事件推送，不得阻塞 UI；
3. **路径状态必须如实**（V1.1 修订，R-8/复核补充）：`sync_source_path`/`set_source`/`refresh` 对「不存在 / 无权限 / 不可访问」分别返回明确的 `error` 状态并提示对应文案（V-21），**禁止沿用上一次的扫描结果或索引冒充新路径的结果**；
4. 桥接不可用时（RK-7），前端降级为**只读浏览**，分类编辑入口禁用并提示（红线 L14）。

## 七、空态、加载态、错误态规范

| 态 | 文案四要素 | 视觉 |
|---|---|---|
| 空态（未设目录） | 标题「还没选择照片文件夹」／说明「选一个存放实况照片的文件夹，程序会按子目录自动归类相册（与备份页共用同一个文件夹）」／建议「通常是你的 iPhone 照片导出目录」／入口「选择照片文件夹」 | 居中插画 + 主按钮 |
| 空态（无实况） | 标题「这个文件夹里没找到实况照片」／说明「实况照片是同名的两个文件：一张图片 + 一段视频」／建议「确认导入时没有把图片和视频拆散」／入口「换个文件夹」「看导入向导」 | 同上 |
| 加载 | 「正在扫描…」+ 计数 | 进度条 |
| 错误（索引） | 标题「相册索引读不出来」／说明「照片本身没有任何问题，只是分类记录损坏了」／建议「可以从文件夹结构重新生成分类」／入口「重建分类」「先看照片」 | 警告色边框卡片 |
| 降级（无 WebView2） | 标题「这台电脑缺少浏览组件」／说明「浏览实况照片需要 Edge 浏览器组件，Windows 10/11 通常自带」／建议「点下面的按钮用浏览器打开」／入口「用浏览器打开」 | 居中说明 |

## 八、交互细则

| 项 | 规定 |
|---|---|
| 键盘 | `Tab` 在卡片间移动焦点；`Enter`/`Space` 播放当前卡片；`Esc` 停止播放并回到封面 |
| 触屏 | 轻点 = 播放/停止（不区分悬停）；网格滚动不做长按菜单，改用**长按 500ms** 唤出卡片菜单 |
| 鼠标 | 悬停仅缩放（D5）；右键唤出菜单 |
| 多选 | 分类栏上方「整理」按钮进入多选模式（`Ctrl/Shift` 点选），批量归类/导出 |
| 播放并发 | 同时最多 1 个卡片播放（新的开始时旧的停止），避免多路解码 |
| 无障碍 | 卡片 `aria-label` = 「文件名，所属相册，点击播放」；焦点环 2px 主色 |
