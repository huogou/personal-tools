### 相册页

| ID | 场景 | 标题 | 说明 | 建议 | 入口 |
|---|---|---|---|---|---|
| V-01 | 相册页首次进入、未选源目录 | 还没选择照片文件夹 | 选一个存放实况照片的文件夹，程序会按子文件夹自动整理成相册（**与备份页共用同一个文件夹**） | 通常是 iPhone 导出的照片目录 | **选择照片文件夹** |

## 三、禁用表述清单（文案红线）

| 禁止写 | 必须写 | 原因 |
|---|---|---|
| 「已修复/修复了损坏的照片」 | 「照片本身没有任何问题，只是分类记录损坏了」 | 红线 L7：不得暗示照片损坏 |
| 「安卓图库原生实况照片」 | 「这是安卓手机可以直接播的 MP4」 | 红线 L7：安卓**不识别**实况照片格式 |
| 「实况照片已导出」 | 「已导出 MP4 视频」 | 红线 L7：「原样复制」≠「格式转换」，须说清 |
| 「转换为实况照片格式」 | 「转换成安卓能播的 MP4」 | 同上 |
| 「支持所有 iPhone 实况视频」「HEVC 肯定能播」 | 「能直接播的直接播，播不出的自动转换」 | **V1.1 新增（R-11）**：U-01 未实测前不得宣称 HEVC 兼容 |
| 「已验证兼容 HEVC（依据注入式测试）」 | 注入式测试结果只允许写「**降级分支可用**」 | **V1.1 新增（复核补充）**：注入式测试只能证明降级分支存在，**不得作为真实 HEVC 兼容性证据** |
| 「正在自动播放」 | 「点一下卡片就会动」 | 强调点按才播的交互契约 |
| 「空间充足」（超时/失败态） | 「未完成检查」 | 继承 V1.2 红线 L4 |
| 「同步到云端 / 在线相册」 | 「本地相册（仅此电脑）」 | 本轮纯离线，不得暗示联网 |
| 「删除原文件安全了」 | 继承 V1.2 #2 底线句原文 | 红线 L6 |
| 「分类已损坏，修复中」 | 「正在整理相册」 | 不得在生成过程中使用破坏性词汇 |
