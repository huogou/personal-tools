## 使用总则

1. **红色按钮（危险）**只出现在涉及覆盖/写入失败的确认场景；其余确认用系统默认样式。
2. 所有弹窗按钮文案用动词（「重新选择」「继续备份」），不用「确定/取消」以外的含糊词。
3. 涉及"删除原文件"的话题，任何场景都附同一句底线：「**未经验证的备份不能作为删除原文件的依据**」。
4. 程序检测不到的事（文件是否损坏、照片是否是实况）一律用"程序不能判断/建议你人工确认"表述。
5. **"不完整"统一口径**：只能表述为「按当前配对规则未找到可匹配的关联文件」，禁止表述为"文件损坏/照片坏了"。
6. **空间与路径检查的失败/超时**必须如实标注"未完成检查"，禁止以"检查通过"或"空间充足"的模糊表述放行。
7. **取消与退出**：备份中不存在"立即强杀退出"路径，只有「继续等待」与「安全取消」（当前条目处理完后停止）。

|---|---|
| 呈现 | 统计卡「不完整 N」黄橙 + 建议行 |
| 标题 | 有 N 组照片不完整（缺图片或缺视频） |

### 7. 预览无法打开（浏览器播放失败）

| 要素 | 内容 |
|---|---|
| 呈现 | 预览页 overlay 错误条（沿用 V1.1 机制）+ 主窗口日志红色行 |
| 标题 | 这段视频在浏览器里放不出来 |
| 说明 | 可能是视频编码（常见如 HEVC）浏览器不支持。**这不代表文件坏了**——原始文件没有被改动，备份后原文件照样完好。 |
| 建议操作 | 用系统自带播放器直接打开原始文件试试；或者正常走备份流程，备份后用「GIF 动图」版看动态。 |
| 返回入口 | 预览页 [返回网格]；主窗口不受影响 |

### 8. 备份目标目录与源目录相同（或互相嵌套）

**8a 目录关系确认拦截**

| 要素 | 内容 |
|---|---|
| 呈现 | messagebox.showerror（**开始备份前硬拦截**） |

| 说明 | 你选的备份输出目录就是照片所在的文件夹，或两个目录互相包含（一个在另一个里面）。这样备份会把文件复制进自己里面，结果不可预测。 |
| 建议操作 | 重新选一个**和照片文件夹完全分开**的文件夹，比如 D 盘新建一个「实况照片备份」文件夹。 |
| 返回入口 | [重新选择]（关闭弹窗并打开目录选择框）——**无"继续"选项，此拦截不可绕过、无普通绕过按钮** |

**8b 目录关系无法确认（V1.1 修订新增，对应裁定 §二.2）**

| 要素 | 内容 |
|---|---|
| 呈现 | messagebox.showerror（与 8a 同级硬拦截） |
| 标题 | 无法确认两个文件夹的关系 |
| 说明 | 程序在检查"照片文件夹"和"备份输出到"的关系时遇到异常（可能是特殊路径或系统限制），为了安全，这次备份不能开始。 |
| 建议操作 | 请把两个文件夹换成更简单的常规路径（如 D 盘根目录下的两个普通文件夹）后重试；如反复出现，请把文件夹路径截图反馈。 |
| 返回入口 | [重新选择]——判定失败一律停止操作，**不得放行** |

### 9. 目标目录空间不足 / 预检未完成 / 写入失败

**9a 空间不足（开始前估算）**

| 要素 | 内容 |
|---|---|
| 呈现 | messagebox.showwarning（开始前拦截） |
| 标题 | 目标硬盘空间可能不够 |
| 说明 | 本次备份大约需要 X GB，目标盘当前只剩 Y GB。空间不足时备份会中途失败，留下不完整文件。 |
| 建议操作 | 换一个空间够的盘，或清理目标盘后重试。（估算值，实际以文件大小为准） |
| 返回入口 | [重新选择]  [仍要继续]（用户自担风险，日志将如实记录） |

**9a-2 空间预检超时 / 检查失败（V1.1 修订新增，对应裁定 Q8：不得误报空间充足）**

| 要素 | 内容 |
|---|---|
| 呈现 | messagebox.askyesno（开始备份时兜底确认） |
| 标题 | 空间检查未完成 |
| 说明 | 因为照片文件夹较大（或读取受限），程序**没有完成**空间检查——**这不是"空间足够"，只是没查成**。空间不足时备份会中途失败，已成功部分会保留。 |
| 建议操作 | 建议先自行确认目标盘剩余空间明显大于照片文件夹体积，再继续；或换一个空间充裕的盘。 |
| 返回入口 | [回去检查空间]（默认） / [我已确认，继续备份]（日志如实记录"预检未完成"） |

**9b 写入失败（过程中）**

| 要素 | 内容 |
|---|---|
| 呈现 | 日志红色行 + 任务卡「⚠ 部分失败」 |
| 标题 | 有文件没写进去 |
| 说明 | 常见原因：目标盘满了、文件被其他程序占用、或目标文件夹没有写入权限。已成功的部分不受影响，原始照片始终没被改动。 |
| 建议操作 | 看操作日志里是哪些文件失败；处理原因（清空间/关占用程序/检查权限）后，重新点「开始备份」——已成功的会自动跳过。 |
| 返回入口 | [打开日志] · [打开备份目录]（检查已写入的部分） |
