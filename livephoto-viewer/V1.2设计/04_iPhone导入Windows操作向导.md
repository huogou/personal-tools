## 向导定位

**给谁看**：第一次用这个工具、或者搞不懂"实况照片为什么传到电脑就不会动了"的用户。

**四步主线**：准备照片 → 导入电脑 → 检查结果 → 先预览再备份。

## 第 1 步：在 iPhone 上准备照片

**页面标题**：先确认手机里的照片是"会动的"

**说明正文**：

1. 打开 iPhone 的「照片」App，找到你想备份的照片。
2. 看照片**左上角**：如果有一个「实况」小标志（ISO 感光符号样式的圆圈），说明它是一张实况照片——按住屏幕松手就能看到当时那一两秒的动态。
3. 没有这个标志的照片就是普通静态照片，它不需要这个工具，直接备份就行。

**⚠ 注意事项**：

- 准备用数据线导入的话，请检查你的数据线**支持传文件**（不是所有充电线都能传数据）。便宜的充电线插上电脑常常只能充电、电脑里看不到照片。
- 「实况」开关如果被关掉了（拍照时顶部的同心圆图标划掉了），新拍的照片不会带动态。想拍会动的，先把这个开关打开。

**本步需要手动**：全部由用户在手机上完成。
**下一步按钮**：「下一步：把照片传到电脑」

## 第 2 步：导入电脑（两条路线，选一条就行）

**页面标题**：把照片传到电脑——两条路，选你顺手的

**路线一：数据线（推荐，最完整）**

1. 用支持传文件的数据线把 iPhone 连到电脑。
2. 手机上如果弹出「要信任此电脑吗」，点「信任」并输入锁屏密码。
3. 打开电脑的「此电脑」→ 找到 iPhone 设备 → 进 `Internal Storage\DCIM` 文件夹，把照片文件夹整个复制到电脑硬盘（比如 `D:\照片\iPhone导出`）。
4. 或者用 Windows 自带的「照片」App 导入（开始菜单搜「照片」→ 导入）。

**路线二：你已经在用的同步/传输方式**

- iCloud 照片、网盘、微信/QQ 文件传输助手等都可以，把照片先弄到电脑某个文件夹里就行。
- 不确定怎么弄的话，优先用路线一。

**⚠ 注意事项（必须如实告知，不承诺）**：

- **不同的手机系统版本、电脑系统版本、相册设置，导出来的文件可能不一样。** 本工具不能保证每种情况都能拿到完整的"图片+视频"两个文件。
- 如果 iPhone 的相机设置里开了「高效」格式，导出的可能是 `.heic` 图片和 `.mov` 视频；如果开了「兼容性优先」，可能只有 `.jpg` 没有视频。**没有视频 = 传到电脑后照片不会动，这是导出方式的问题，不是照片坏了。**
- 用微信等聊天工具传照片，通常**只传静态图片、丢掉动态**，不建议用这种方式备份实况照片。

**本步需要手动**：全部由用户完成。
**下一步按钮**：「下一步：检查导入结果」

## 第 3 步：检查导入结果

**页面标题**：扫描一下，看看传全了没有

**说明正文**：

1. 回到本工具主窗口，点「照片文件夹」旁边的「浏览」，选中刚才照片导入到的文件夹。
2. 点绿色按钮「只读预览」——它会扫描这个文件夹（包括子文件夹），然后在浏览器里打开一个预览页。**放心，这一步只是看，不会复制、不会修改你的任何文件。**
3. 扫描完，回到本工具窗口看统计结果：

| 结果 | 意思 | 你该做什么 |
|---|---|---|
| 完整配对 | 图片和视频都找到了，这张照片的动态保住了 | 不用管，等备份 |
| 待确认 | 同一个名字的文件出现了好几份，程序不敢替你做主 | 点进预览页逐组核对，留下要的那份 |
| 不完整 | 当前配对规则下**未找到可匹配的关联文件**（只有图或只有视频）——程序不能判断文件是否损坏 | 先别删任何文件！见下方说明 |
| 失败 | 个别文件读不出来 | 看操作日志里的具体原因 |

**⚠ 关于"不完整"（重要）**：

- 实况照片 = 一张静态图 + 一小段视频，两个文件名字相同。程序只按文件名配对，它只能告诉你"**按当前配对规则没有找到匹配的关联文件**"，**不能判断文件是不是坏了**。
- 遇到"不完整"，通常是导入的时候只传了一半（比如某些网盘默认不传视频）。建议：换个方式重新导一次（优先数据线），然后再扫一遍。
- 也可能是你自己把某张普通照片和某个视频放在了一起凑巧同名——在预览页点开看一眼就能确认。

**本步**：选目录、点预览 = 用户手动；扫描、配对、分类 = 程序自动。
**下一步按钮**：「下一步：先预览，再备份」

## 第 4 步：先预览，再备份（安全三步走）

**页面标题**：最后一步——先看，再存，后删

**说明正文**：

**第①看**：在预览页（浏览器里）点几张照片，确认动态正常播放。有的视频在浏览器里可能放不出来（提示编码不支持），不代表文件坏了，备份后原文件还在。

**第②存**：

1. 在主窗口选好「备份输出到」的文件夹（建议 D 盘，**别和照片文件夹选同一个**）。
2. 点「开始备份」，会弹出确认框告诉你：备份多少张、存到哪里、大概需要多少空间。确认后才开始。
3. 备份完成后，窗口里会出现「打开备份目录」的快捷入口。

**第③删（最关键的一句）**：

> **打开备份目录，随机点开几张照片确认能正常打开之后，才考虑删除电脑或手机上的原文件。没验证过备份，一个原文件都别删。**

**⚠ 注意事项**：

- 备份前确认目标硬盘剩余空间够（确认框会帮你估算）。
- 重复备份不会重复转换，已经处理过的照片会自动跳过。
- 本工具预览时**从不修改你的原照片**；备份只是"复制"，原文件始终留在原地，直到你自己动手删。

**本步**：选输出目录、点备份、确认 = 用户手动；复制/转 GIF/生成网页 = 程序自动。
**结束按钮**：「完成，去扫描」

## 程序内呈现的落地要求（给开发）

| 项 | 要求 |
|---|---|
| 入口 | ① 主窗口右上「? 使用帮助」；② 帮助区卡片 1/2/3（分别跳第 1 步、第 3 步表格、第 4 步）；③ 首次打开自动弹第 1 步（见下行弹出规则） |
| 首次弹出规则（裁定 Q6） | **仅首次启动弹一次**（配置 flag 落盘）；**用户可随时关闭**（点 × 或「直接开始」），关闭后**不再自动弹**；**可随时从主窗口右上「? 使用帮助」或帮助区卡片重新打开**；任何情况下不得每次启动都弹 |
| 窗口 | `Toplevel`，520×560，不可调太小（`minsize(480, 520)`），置顶于主窗口 |
| 文本 | `Text` 组件只读渲染，表格用缩进文本近似；⚠ 段落用黄底 tag |
| 翻页 | 「上一步/下一步」按钮切换缓存页内容；步骤进度点用 ● ○ 字符 |
| 记忆 | 弹出标记与 V1.1 版本绑定（升级大版本可重新提示一次，需另行裁定，本轮不做） |
| 关闭 | 点右上 × 直接关闭，无需确认 |
