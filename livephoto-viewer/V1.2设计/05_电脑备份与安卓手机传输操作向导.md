## 向导定位

**给谁看**：备份完成后，想把照片转到安卓手机上看的用户。

**核心提醒（向导首页就要讲清楚）**：

> iPhone 的实况照片是苹果的专属格式（一张图 + 一段视频绑定播放）。**安卓手机的相册通常不认识这种绑定关系**——传过去之后，你大概率只能看到一张静态图片。这不是文件坏了，是安卓相册不认。所以先想清楚你要什么，再动手。

## 第 1 步：选择你的目标（四选一，V1.2 修订：与第 2 步及验收检查表 E-3 对齐）

**页面标题**：你想在安卓手机上得到什么？

四个目标卡片（单选，点选后高亮）：

| 选项 | 一句话 | 适合谁 |
|---|---|---|
| **A. 保留原始素材** | 图片和视频两个文件都原样传过去，以后随时可以找回完整动态 | 想长期归档、以后可能换回 iPhone 的人 |
| **B. 方便看动态（GIF）** | 转成 GIF 动图传过去，点开就动，任何手机都能看 | 主要想给家人朋友看"会动的照片"的人 |
| **C. 传原视频文件** | 把原始视频文件传过去，用手机播放器看完整动态 | 画质优先、不介意手动点开视频的人 |
| **D. 只要静态照片** | 只要那张主图，动态无所谓 | 只是要普通照片的人 |

**⚠ 选之前想清楚**：四个目标对应的做法完全不同，不能混。选错也不会丢数据（原文件还在电脑上），只是白传一遍。

**下一步按钮**：「下一步：看对应的方案」

## 第 2 步：方案与限制（按第 1 步的选择显示对应内容）

### 目标 A：保留原始素材

**怎么做**：把备份输出目录里「原始文件」文件夹中的**成对文件**（同一个名字的 `.heic` 图 + `.mov` 视频）一起传到手机。

| 项 | 说明 |
|---|---|
| 程序支持 | ✅ 已实现——备份时已把成对原文件复制到 `原始文件\`，直接传即可 |
| 优点 | 素材最完整、画质无损；两个文件都在，随时能找回动态 |
| **限制（必须告知）** | 安卓相册**通常把它们当两个独立文件**：图库里看到的是一张静态图，视频要单独点开播。不能像 iPhone 那样按住就出动态 |

### 目标 B：方便看动态（GIF）

**怎么做**：把备份输出目录里「GIF动图」文件夹中的 `.gif` 文件传到手机。

| 项 | 说明 |
|---|---|
| 程序支持 | ✅ 已实现——备份时勾选「转为 GIF 动图」即可生成 |
| 优点 | 任何安卓手机、任何相册都能直接看动态，还能发微信（注意微信可能再次压缩） |
| **限制（必须告知）** | GIF 画质和色彩比原片差（GIF 格式天生只有 256 色）、每张约 2MB、无声（实况本来也无声）；它是"模仿动态"，不是实况照片本身 |

### 目标 C：传"视频版"动态（如实说明能力边界）

**页面显示**（必须如实，不得虚构按钮）：

> 你的电脑上已经有原始视频文件（`.mov` 或 `.mp4`），把它传到手机就能用手机播放器看完整动态。
>
> ⚠ 说明：
> - 本工具**不能**把视频单独转成其他格式（如 mp4 转码），它只会"原样复制"。`.mov` 文件大部分安卓手机的视频播放器能直接放；如果放不了，装一个免费播放器（如 VLC）即可。
> - 视频方案看到的动态和实况照片的"按住播放"体验不一样，它就是一段普通视频。

| 项 | 说明 |
|---|---|
| 程序支持 | ⚠️ 部分——只支持"**原样复制** `.mov/.mp4` 文件"（复制 ≠ 格式转换，文件内容一个字节都不变）；**不支持**任何格式转换（如 MOV→MP4 转码，本轮不实现、不提供按钮） |
| 优点 | 动态完整、画质无损 |
| 限制 | 图库里可能缩略图空白或被当成普通视频；`.mov` 兼容性看具体手机 |

### 目标 D（合并说明）：只要静态照片

> 直接传「原始文件」里的 `.heic` 图——但注意：**很多安卓手机打不开 `.heic`**。如果打不开，说明你的导出方式给的是 HEIC 格式；最省事的办法是在 iPhone 上用「隔空投送/微信」以外的方式重新导出 JPG，或用电脑工具转换。本工具**不做图片格式转换**（未实现，不提供按钮）。

**下一步按钮**：「下一步：怎么传到手机」

## 第 3 步：传输到安卓手机（按你的条件选一条）

**页面标题**：三种传法，选你现有的条件

| 路线 | 怎么做 | 适合 |
|---|---|---|
| **1. 数据线** | 手机用数据线连电脑 → 手机弹窗选「文件传输/MTP」→ 在电脑「此电脑」里打开手机存储 → 把文件复制进去 | 最直接，速度最快，推荐 |
| **2. 局域网/本地工具** | 你如果已经在用本地网络传输方式（如路由器自带的共享、SMB、你熟悉的免费局域网工具），按它的说明传 | 不想插线 |
| **3. 云盘/同步盘** | 传到你在用的云盘，手机端再下载 | 文件多、两台设备不在身边 |

**⚠ 注意事项**：

- 不假设你装了某个特定 App；上面只列"类型"，具体以你手机和已有服务为准。
- 传输大视频时保持手机亮屏、别断线（MTP 传输中断最常见）。
- 用微信/QQ 传 GIF 可以，但传原始 `.mov/.heic` 会被压缩甚至改格式，**传输原始素材请走数据线或云盘**。

**下一步按钮**：「下一步：在手机上检查」

## 第 4 步：在安卓手机上验证（删任何东西之前）

**页面标题**：先确认能打开，再谈删原文件

**核对清单（勾选式，程序内可勾）**：

- ☐ 文件都传完了：手机上看到的文件数量 = 电脑上选中的数量
- ☐ 静态图能打开：随机点 3 张图，都能显示
- ☐ 动态能播放：
  - 目标 B（GIF）：点开就动 ✓
  - 目标 A/C（原始文件）：`.mov` 视频能用手机播放器播放 ✓
- ☐ （仅目标 A）明白：图库里看到静态图是**正常的**，动态在单独的视频文件里

**⚠ 三条铁律**：

1. 手机上"只看到静态图片"≠ 文件损坏，多数是安卓相册不认实况格式（这正是本向导开头说过的）。**本工具不能保证安卓手机图库把传过去的文件识别为原生实况照片**——原生识别取决于手机系统与图库对相应格式及关联机制的支持，与文件本身无关。
2. **未经验证的备份不能作为删除原文件的依据**：手机上验证通过之前，不要删电脑上的备份；电脑备份验证通过之前，不要删 iPhone/电脑上的原文件。一层一层来。
3. 传完先别清空回收站/云盘回收站，万一传坏了还有救。

**结束按钮**：「完成」
