════════ A. Google / Android 官方（developer.android.com）════════
A1  Motion Photo format 1.0（英）
    https://developer.android.com/media/platform/motion-photo-format
    https://developer.android.com/media/platform/motion-photo-format?hl=zh-cn   （中文）
    https://developer.android.com/media/platform/motion-photo-format?hl=zh-tw   （繁中）
    发布方：Android Developers｜等级：官方一手·规范性文件
    支撑：3.2 全部（单文件结构、文件名正则、Camera/Container/Item XMP、MicroVideo 系列废弃、HEIC/AVIF 与 mpvd box、Item:Mime 允许 video/quicktime、PresentationTimestampUs）
    关键原文："These properties were part of the Microvideo V1 specification. They are deleted in this specification and must be ignored if present. In particular, the MicroVideoOffset attribute is replaced by the GContainer:ItemLength value for locating the video data in the file."
    关键原文："Motion Photo files consist of a primary still image file, JPEG, HEIC, or AVIF, with a secondary video file appended to it."
    关键原文（文件名）："^([^\\s\\/\\\\][^\\/\\\\]*MP)\\.(JPG|jpg|JPEG|jpeg|HEIC|heic|AVIF|avif)"
    关键原文（HEIC 必备）："[HEIC/AVIF-based motion photos] Required for the primary media item. Must have a value equal to 8, the header length of the Motion Photo Video Data ('mpvd') box."
    规范性引用含：T.81 JPEG、ISO/IEC 23008-12 HEIF、AVIF、Ultra HDR、ISO 16684-1 XMP Part 1、Adobe XMP Part 3、ISO/IEC 14496-10 AVC、ISO/IEC 23008-2 HEVC、AV1、ISO/IEC 14496-12 ISOBMFF、ISO/IEC 14496-14 MP4、Apple QuickTime File Format (MOV)
A2  ExoPlayer / Media3「Images」
    https://developer.android.com/media/media3/exoplayer/images
    等级：官方一手
    支撑：3.2「品牌/相册 App 兼容性」中「框架层已支持」的依据
    表格原文：JPEG Motion Photo = YES（Still image and video supported）；HEIC Motion Photo = YES；HEIF/HEIC = YES；AVIF (baseline) = YES（Decoded on Android 14+ only）；GIF = NO
    注意：这是 Media3/ExoPlayer 播放库能力，不等于各品牌默认相册 App 一定识别，报告据此不虚构品牌结论。
A3  Media3「Retrieving metadata」
    https://developer.android.com/media/media3/exoplayer/retrieving-metadata
    等级：官方一手
    支撑：3.2 元数据解析；官方提供 `MotionPhotoMetadata` 条目，可提取图片与视频部分的 offsets 与 lengths。
A4  MediaStore.Files.FileColumns
    https://developer.android.com/reference/android/provider/MediaStore.Files.FileColumns
    等级：官方一手
    支撑：常量 `SPECIAL_FORMAT_MOTION_PHOTO`（表示该媒体项为 Motion Photo）、`DATE_TAKEN`（源自 METADATA_KEY_DATE 或 ExifInterface.TAG_DATETIME_ORIGINAL）。
A5  MediaStore.MediaColumns（RELATIVE_PATH / XMP）
    https://developer.android.com/reference/android/provider/MediaStore.MediaColumns.html
    等级：官方一手
    支撑：3.3「自动识别目标照片目录」；原文 "This value should only be used for organizational purposes, and you should not attempt to construct or access a raw filesystem path using this value"；insert 时为 NULL 则按 MIME 放到相关默认位置（image/jpeg → DIRECTORY_PICTURES）；XMP 列（API 30）索引 ISO 16684-1 XMP 元数据。
A6  CloudMediaProviderContract.MediaColumns
    https://developer.android.com/reference/android/provider/CloudMediaProviderContract.MediaColumns
    等级：官方一手
    支撑：`STANDARD_MIME_TYPE_EXTENSION_MOTION_PHOTO`（API 33，Photo Picker 要求对 Motion Photo 打特殊格式标记）。
