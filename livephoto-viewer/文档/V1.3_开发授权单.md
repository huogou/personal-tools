## 三、红线重点提示（全文见 README §四，共 14 条；以下 5 条最易踩，先记住）

1. **`build_html` 仅限丙案**：只删 `mouseenter`/`mouseleave` 两行悬停绑定 + 点击 toggle（满足 P-10 幂等），**其他模板/路径/生成逻辑一字不动**；`build_preview_html` 及其余 12 个受保护函数**零改动**（清单见 05 号 §1.3）；
2. **`webview.start(http_server=False)` 强制写法**，页面一律 `file://` 加载——出现任何端口监听 = 违反红线 L11；
3. **`.processed.json` 绝对不碰**：新分类数据写独立 `相册索引.json`，两者互不影响；
4. **取消/退出无强杀**：备份取消、扫描取消、导出取消都是"当前条目完成后停止"；
5. **不得宣称 HEVC 兼容**：U-01 真实样本实测前，任何输出（代码注释/日志/文档）不得出现"支持 HEVC"表述；注入式测试只能证明降级分支。
