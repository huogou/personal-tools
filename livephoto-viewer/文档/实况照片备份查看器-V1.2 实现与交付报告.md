## 5. Q4 进度回调实现说明（任务书 §3 逐条对照）

| 约束 | 实现与实测 |
|---|---|
| 不传回调时旧调用行为兼容 | `progress_cb=None` 默认参数；CLI `--cli`/`--preview` 不传回调，行为与 V1.1 一致（A-8/A-9/A-10 实测） |
| 仅显式返回 `False` 表示请求取消 | `_notify_progress()` 以 `return r is False` 判定；返回 `None`/`True`/其它一律继续 |
| 正常回调返回 `None` 时继续 | A-10 实测：回调返回 `None` 时全量备份正常完成（ok=4/fail=1，与不带回调一致） |
| 回调只报告进度与取消，不改业务规则 | 载荷 `{"event":"start"/"item","index","total","name"}`；A-10 实测带/不带回调 `.processed.json` 逐字节一致 |
| 取消在安全检查点执行，不强制中断当前文件写入 | 取消经回调在**条目之间**返回 `False`；当前条目的复制/GIF 转码完整做完才 break；K-4 实测取消后已复制文件全部可打开，无半成品 |
| 取消不得记为成功，未完成项不得被写为已完成 | 取消后 `save_done` 只写已处理条目的键；未处理条目**无任何键**（K-4/A-11 实测：记录 3 条 = 处理 3 组，未处理 2 组无记录） |
| 回调异常必须有明确处理策略 | `_notify_progress()` 捕获异常 → 记 `[警告] 进度回调异常（本次进度未上报，备份继续）` 并继续，**不静默改变结果**；K-12 实测：回调全程抛异常时备份仍完成 ok=4/fail=1，留 6 条警告 |

## 6. 路径安全与空间预检（任务书 §4 逐条对照）

| 要求 | 实现与实测 |
|---|---|
| 检查源=输出、目录嵌套、规范化后路径关系 | `check_path_relation()` 返回 `ok/same/out_in_src/src_in_out/unknown`；K-1 覆盖 10 个场景全对 |
| 无法可靠判定 → 阻止备份并提示重选 | 注入路径异常后返回 `unknown` → 弹 06 号 #8b「无法确认两个文件夹的关系」，**无放行路径**（D-8 实测） |
| 不得提供普通风险绕过按钮 | 8a/8b 弹窗只有「重新选择」；弹窗内不存在「继续/忽略」按钮 |
| 空间预检区分已完成/超时/失败 | `estimate_backup_size()` 返回 `ok/timeout/error`；K-2 四分支实测全对（超时用可注入时钟、失败用注入权限异常，确定性触发） |
| 超时/失败不得显示「空间充足」 | 三态文案实测：`预计需要 3.0 GB · 目标盘可用 10.0 GB` / `空间检查未完成（目录过大已跳过）…` / `空间检查失败（可能无读取权限）…`，**全流程无「空间充足/空间足够」字样** |
| 必须处理写入时的磁盘满、权限不足、写入失败 | 沿用既有 try/except 逐条捕获 → `[失败] {name}: {原因}` + 任务卡「⚠ 部分失败」+ 9b 文案（磁盘满/被占用/无写权限）；已成功部分不受影响，源文件零改动 |

## 10. 失败、未验证事项与剩余风险

### 10.1 失败项

**无。** A 组 10/10 PASS，K/B 组 19/20 PASS，EXE 构建 exit=0，EXE 冒烟通过。

开发过程中发现并已修复的 5 个缺陷（均为实现期自查发现，非设计问题）：

| # | 缺陷 | 后果 | 修复 |
|---|---|---|---|
| F-1 | `tkinter.font.Font(size=10.5)` | Tk 只接受整数 → GUI **无法启动** | h3 取 10pt（D-12） |
| F-2 | `tk.Button(disabledbackground=…)` | Tk 无该选项 → GUI **无法启动** | 新增 `enable_btn()` 统一处理禁用态 |
| F-3 | `Entry.trace_add()` | Entry 无该方法 → 目录输入即崩 | 改用 `StringVar` + `textvariable` 双向绑定 |
| F-4 | `Text.tag_configure(spacebefore/spaceafter)` | 无效选项 → 向导页渲染即崩 | 改为合法的 `spacing1/spacing3` |
| F-5 | 折叠明细 `data[fold["kind"]]` 键与状态 kind 不一致 | `KeyError('warning')` → **已扫描态整块不渲染** | 折叠项新增 `data_key` 字段 |
