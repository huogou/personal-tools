## 2. 项目定位

**自用的 iPhone 实况照片备份与查看小工具。**

解决的问题：iPhone 的实况照片 = 主图（`.heic`）+ 一段小视频（`.mov`）两个文件。
上传到云盘/移动硬盘后，这两个文件很容易被拆散或丢掉视频，导致照片变成"不会动"的静态图。

面向用户：彦祖本人（自用，无对外分发）。

## 3. 项目目标

- 原样备份 `.heic + .mov` 双件套，**永不丢失动态**；
- 自动生成 GIF 动图与网页查看器，使实况照片在任意电脑上可动；
- 增量备份：重复运行自动跳过已处理照片；
- 绿色单文件分发：无需安装 Python 即可运行。

## 5. 技术架构

| 层 | 技术 | 说明 |
|---|---|---|
| 语言 | Python 3 | 单文件主程序 |
| 图像 | Pillow | HEIC/GIF 处理 |
| 视频 | imageio-ffmpeg | 内置 ffmpeg 引擎，HEIC 动态转换不依赖外部软件 |
| 打包 | PyInstaller | 生成绿色单文件 EXE（无需目标机安装 Python） |
| 界面 | 自研 GUI | 「备份 / 相册」双页签；备份页三输入项，相册页内嵌 WebView2 |
| 相册页 | WebView2（pythonnet 直驱） | 零端口、纯离线；本地视频 file:// 直解，失败转 H.264 MP4 兜底 |

**设计取向**：零第三方服务、零联网、纯本地处理——与全库"个人开发者成本优先 + 无服务器"原则一致。

### 关于 `dist\`

- `dist\` 是打包产物目录，内含 **50.7 MB** 的可执行文件（V1.3 修复版，53,144,147 B）；
- 该 EXE 是满足"无需安装 Python 即可运行"这一目标所必需的交付物，**不建议删除**；
- 但从项目整洁角度，打包产物与源码同层摆放并不理想（见第 9 节 T1）。

### 备份产物结构（工具运行时生成于用户指定的输出目录）

```
输出文件夹\

└── 网页查看器\    双击 index.html，浏览器内像手机一样浏览（悬停自动播放）
```
